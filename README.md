
# NumPy Array Operations

## 1. Project Overview
This project demonstrates basic numerical operations using
NumPy arrays in Python.

## 2. Objective
The objective is to create two NumPy arrays and perform
addition, subtraction, multiplication, and division.

## 3. Technologies Used
- Python
- NumPy
- Visual Studio Code
- Git and GitHub

## 4. Project Approach
1. Imported the NumPy library.
2. Created two numerical arrays.
3. Displayed both arrays.
4. Checked their shapes.
5. Performed four arithmetic operations.
6. Displayed the results.
7. Explained vectorized operations.

## 5. Features
- NumPy array creation
- Array shape inspection
- Addition
- Subtraction
- Multiplication
- Division
- Vectorized numerical calculations

## 6. Installation and Configuration

Install Python from https://www.python.org/downloads/

Install NumPy using:

```bash
python -m pip install -r requirements.txt
```

## 7. How to Run

Open a terminal in the project directory and run:

```bash
python app.py
```

## 8. Expected Results
The program displays two arrays, their shapes, and the
results of addition, subtraction, multiplication, and division.

## 9. Deployment Configuration
This is a local Python command-line application. It does not
require a web server or public website deployment.

The required Python dependency is recorded in
requirements.txt. Instructions for installation and execution
are provided in this repository.

## 11. Outcome
The project demonstrates how NumPy performs element-wise
arithmetic and provides information about array dimensions.

This project strengthens basic Python programming skills
and introduces numerical computing concepts used in
data analysis and machine learning.
